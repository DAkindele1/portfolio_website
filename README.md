# Akindele David Portfolio

Personal portfolio website for Akindele Oluwasegun David, a software developer focused on thoughtful interfaces, clean code, and continuous learning.

## Features

- Responsive portfolio layout for desktop, tablet, and mobile
- Fixed desktop navigation with a mobile menu
- About, experience, skills, and contact sections
- GitHub, email, and telephone contact links
- Smooth scrolling and lightweight entrance animations
- Accessible navigation labels and interactive controls

## Built With

- React
- Vite
- JavaScript
- CSS
- [Lucide React](https://lucide.dev/) for icons

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/DAkindele1/portfolio_website.git
cd portfolio_website
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

### Create a Production Build

```bash
npm run build
```

The production files are generated in the `dist` directory.

### Preview the Production Build

```bash
npm run preview
```

## Project Structure

```text
portfolio_website/
├── public/
├── src/
│   ├── main.jsx
│   └── styles.css
```

## Customization

Update the content and links in `src/main.jsx`. Visual styles, spacing, colors, typography, and responsive breakpoints are defined in `src/styles.css`.
